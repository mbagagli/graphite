Set up your workspace.

Install the desktop app using the platform notes. Graphite keeps its own database and indexes. Your Zotero library and original PDFs remain unchanged.

Start with the demo

Choose Use demo data at the top of the Data Source panel, then follow the guided tutorial. Real metadata is included; the Zenodo PDF archive and models are explicit downloads.

The Windows x64 beta uses CPU for built-in answers. Find your beta on GitHub Releases and look for the Windows setup executable under Assets.

macOS releases are unsigned and unnotarized. After checking the release source and checksum, follow Apple's app-specific opening instructions if a trusted download is blocked. Keep Gatekeeper enabled.

Connect Zotero

  1. In Zotero Desktop, open Settings > Advanced and enable Allow other applications on this computer to communicate with Zotero (official setup). Keep Zotero running while connecting Graphite.
  2. Make the required PDFs available locally. In Graphite, choose Data Source > Use Zotero and select a library.
  3. Choose Prepare library for AI. Graphite synchronizes metadata and available text, then prepares citations and semantic passages.
  4. Install the embedding model if requested, resume, and review coverage. Preparation covers the selected library, not only the visible collection.

Detailed preparation reference

Explore relationships.

The canvas starts with all papers in the active library. Collections and Lenses show their available members; choose All papers to restore the complete library. Larger libraries can take longer to lay out.

Select a paper to focus it and open its inspector. Double-click to move closer. Switch between spatial 3D and flat 2D; use Fit graph to restore an overview.

Small nodes also respond just outside their visible edge, so you can select papers while zoomed out. Where targets overlap, the paper nearest the viewer wins. Zoom in or rotate the 3D view to reach a paper behind it.

Find similar retrieves a semantic neighborhood when indexed evidence is available. Explore citations follows citation relationships. Opening a search result selects and centers that paper like a canvas click. Use search checkboxes for multiple selection. Use Back to restore previous navigation, paper selections and camera position. Clicking empty graph space clears selection and focus without moving the camera. Clear selection also closes its panel; reopen it to use Undo for selection only.

Show connections controls visible relationship types. TOPIC MAP explains category colors, and Group By Topic changes the layout. Prepare the library for AI first: automatic topics reuse the semantic index. Until a map is available, papers stay neutral; citations remain usable. Labels describe content-similarity groups, not scientific proof. Topic Map shows coverage and representative titles on hover. Collections reuse the library-wide map; Zotero tags are unchanged.

Open Analytics to inspect the current collection and select a publication year to see its papers. Counts describe your loaded corpus, not all published research.

Graph navigation reference / Help and Analytics reference

Find the right passage.

Keyword
Search metadata and available indexed text without an AI model.
Semantic
Retrieve by meaning using the installed embedding model and prepared index.
Hybrid
Combine lexical and semantic retrieval. Inspect the returned passages and their provenance.

Use Search library in the top bar. Select a result to inspect its paper and move from discovery to reading. Missing text or incomplete coverage limits what retrieval can find.

Keep an investigation.

A Lens is a named, fixed set of papers with an optional research question. It is saved locally for the current library and survives restarting Graphite.

  1. Select papers and choose Save selection as Lens in the sidebar. Name it, review the papers, and save.
  2. Click its name to reopen it. Use Edit beside the name to rename it, change its question, or remove papers.
  3. To add papers, return to All papers, select them, then edit the target Lens and choose Add selected papers.
  4. Choose Ask about this Lens to open TYRION with This Lens only selected. Review the question before sending.

Keep an answer's source papers by choosing Temporary Lens beneath it, then Save temporary Lens. Temporary Lenses disappear after restarting unless saved.

Lenses can contain up to 1200 papers; a Lens-only AI request accepts 1-64 available papers and excludes earlier answers. Missing papers stay in the saved membership, labeled unavailable. No evidence is borrowed from the whole library when a Lens is empty.

Switching libraries shows separate Lens lists. Deleting a Lens opens a confirmation view: choose Confirm delete Lens to remove it, or Keep Lens to return to the draft. Deleted Lenses stay deleted after restart; papers are kept. Membership is a snapshot, not an automatically updating search; graph camera positions are not saved.

Complete Lens guide and recovery notes

Read and annotate.

Choose Open paper in a paper's inspector. The Reader provides page navigation, zoom, text search, and multi-PDF controls. Returning to the graph preserves your context.

Edit PDF opens a separate local copy for highlights, notes, drawing, text-run replacement, and page changes. Save in Graphite or export a PDF. Search and citation provenance continue to use the original source text.

PDF editing guide and format limitations

Ask with a scope.

Install the embedding/search model in Data Source. Configure an answer model separately in TYRION > Setup. Models run locally; initial downloads require your explicit action.

Graphite finds passages in your papers; the answer model writes a response using those passages. Keep Built-in model to let Graphite download and run it for you. If you already run a model in Ollama or LM Studio, choose Advanced: answer model > Another app on this computer and enable that app's local server. Graphite still handles paper search and citations.

OpenAI-compatible describes the connection format. It does not connect Graphite to OpenAI. The optional API key is for the local server only; direct LAN, VPS, GPT and Claude cloud connections are not supported.

Choose the current paper, a selection, a Lens, a collection, or the library as context. Start with one prepared paper and a specific question. Open the answer's source citations and check the supplied evidence in the Reader.

Library prepared and Ready to ask TYRION are different states. You need indexed passages and an available answer provider to ask grounded questions. Neither state guarantees scientific correctness.

Saved conversations can be reopened, deleted, or exported as Markdown. Use the first-question walkthrough to practice verification.

Get moving again.

Preparation paused or was interrupted

Install a missing embedding model, then choose Resume preparation. Cancel keeps verified PDFs and completed indexing. After restarting Graphite, resume manually. An interrupted ZIP download may restart.

A paper has no usable text

Check that its PDF is available. A scan may need OCR before it provides passages. Graphite reports missing files and scans while continuing with other papers; preparation does not install OCR software.

The graph works, but PDFs or AI do not

The browser preview supports real metadata, graph navigation, and keyword search. Native PDF access and model execution require Graphite Desktop. In the desktop app, review preparation coverage and model setup.

Zotero is closed

Previously synchronized metadata and text remain searchable. A previously resolved PDF can reopen while its file remains at the validated location. New synchronization requires Zotero to be available.

I need to rebuild an index

Rebuild text index clears Graphite's copied text and lexical index. Run Prepare library for AI to regenerate available text. Rebuild cache regenerates the Graphite-owned Zotero partition. Neither edits Zotero.
