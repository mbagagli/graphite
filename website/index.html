Graphite owns its indexes. Zotero remains the bibliographic source of truth.

Read-only Zotero connection
Graphite reads through Zotero's local API. It does not edit Zotero's database or attachments.
Local retrieval and generation
Keyword search works without a model. Optional search and answer models are explicitly downloaded, then run locally.
Visible limits
Source passages and citations can be inspected. An answer is not proof; check claims against the paper. Missing evidence should remain visible.

macOS Apple Silicon

Open the disk image and drag Graphite into Applications. The app carries an ad-hoc signature and is not notarized.

Check the release source and checksum before opening. If macOS blocks a trusted download, follow Apple's app-specific opening instructions. Keep Gatekeeper enabled.
